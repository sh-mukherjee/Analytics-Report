09   Appendix

Methodology

Universe. {{ meta.n_names_word|capitalize }} {{ meta.market }}-listed stocks, {{ meta.equal_weight }} each at inception. Benchmark. {{ meta.benchmark_name }} ({{ meta.benchmark }}), buy-and-hold. Rebalancing. At each {{ rebalance_freq }} close, either through trading or by construction, the weights are reset to target. Between rebalances the weights drift with prices, so the reported monthly return is a true buy-and-hold return for that month.

Returns. Adjusted close, so dividends are reinvested and returns are total returns. Monthly returns are compounded from daily returns, not sampled from month-end prices. Inception. The first month-end on which all {{ meta.n_series }} series have a price ({{ meta.start }}); the partial first calendar month is excluded so every observation is a complete month.

Statistics. Volatility is the sample standard deviation of monthly returns times √12. Sharpe and Sortino use annualised arithmetic mean excess return over annualised volatility and downside deviation, with a {{ meta.risk_free_text }} risk-free rate. Alpha and beta are OLS on monthly returns with Newey–West (HAC) standard errors. M² rescales the portfolio Sharpe ratio by benchmark volatility.

Attribution. Return contributions are daily weight-times-return terms, each linked forward at the cumulative growth rate, so they sum exactly to the cumulative return. Risk contributions are marginal contributions to variance from the monthly covariance matrix and sum to 100%.

Assumptions and limitations

  • Risk-free rate. A {{ meta.risk_free_text }} risk-free rate is the base case. If cash yields were materially positive over the window, Sharpe and Sortino are flattered relative to a cash-based calculation; ranking against the benchmark is unaffected because both series share the assumption.
  • Ex-post selection. The {{ meta.n_names_word }} names were chosen knowing how the period turned out, and they are not a random sample of {{ meta.market }} equities. The report describes what this basket did, not what a repeatable strategy would have earned.
  • One regime. {{ meta.years }} years covering a single market cycle. Results are conditional on that sequence.
  • Execution frictions. No taxes, bid–ask spread, market impact, lot-size rounding or dividend withholding tax is modelled. The cost table brackets the rebalancing component only, not round-trip costs on the initial purchase.
  • Benchmark total return. The vendor history records {% if meta.benchmark_divs %} {{ meta.benchmark_divs }} distribution(s){% else %} no distributions{% endif %} for the benchmark over this window. If the fund distributed and the series does not capture it, the benchmark's total return here is understated and every active-return figure is correspondingly overstated.
  • Sampling noise. With {{ meta.obs.split(' ')[0] }} monthly observations, annualised volatility carries a wide relative standard error and Sharpe ratios are correspondingly imprecise. Differences of a few tenths in Sharpe are not meaningful.
  • Survivorship and corporate actions. All {{ meta.n_names_word }} companies remain listed; a basket formed at inception could have included names that did not survive. Vendor-adjusted prices may be revised after splits and special dividends.
